# AI Unified Feature Contract and Dataset Manifest

Branch: `codex/ai-unified-feature-contract-and-dataset-manifest`

## Objective

This branch adds a paper/shadow-only validation layer for Qlib and IA Shadow datasets.
It blocks training and inference inputs when the feature matrix contains schema drift,
lookahead features, target leakage, NaN, infinite values, dtype mismatches, range
violations, duplicated timestamps or unsafe runtime flags.

## Invariants

The implementation is audit-only. It does not train models, does not run inference,
does not change active signals, does not alter the official training dataset, does not
write to `trades_master`, does not write to the Freqtrade database, does not send
orders and does not change risk.

Required safety flags in every report:

```json
{
  "paper_only": true,
  "shadow_only": true,
  "runtime_mode": "paper",
  "live_trading_enabled": false,
  "order_submission_enabled": false,
  "real_order_submission_enabled": false,
  "exchange_private_access": false,
  "sends_orders": false,
  "changes_risk": false,
  "changes_model": false,
  "changes_training_dataset": false,
  "writes_trades_master": false
}
```

- `data/features/training_dataset_quality_gated_binance_1m.parquet`

## Blocked columns

The feature matrix blocks these patterns:

- `future_ret_*`
- `target_*`
- `label_*`
- `pnl_*`
- `profit_*`
- `exit_*`

`future_ret_*` is blocked as a source column because it is explicit lookahead.
The target/outcome patterns may exist in supervised labeling artifacts, but they are
excluded from the auto-selected feature matrix and are blocked if explicitly selected as
model input features.

## Validations

The contract validates:

- feature names;
- feature order;
- dtype;
- NaN in the final feature matrix;
- infinite values;
- min/max ranges;
- forbidden feature patterns;
- duplicated timestamps;
- dataset emptiness;
- schema hash;
- feature order hash;
- dataset hash;
- safety flags.

The CLI returns status `ok` with exit code `0` when all checks pass. It returns status
`blocked` with exit code `1` when any required check fails. By default, the CLI
drops historical rolling warm-up rows with NaN from the audit-only feature matrix and
reports `dropped_nan_rows`; it does not mutate the source parquet. Use `--no-drop-nan`
when the desired gate is raw-row strictness.

## Correção operacional v3 — `model_backend`

O campo `model_backend` em `data/predictions/latest_qlib_predictions.parquet` é metadado/contexto do artefato de predição Qlib. Ele não é feature de entrada, não entra na matriz X e não deve bloquear o contrato como `unexpected_features`. A validação continua bloqueando colunas de vazamento explícito, como `future_ret_*`, e targets indevidos quando selecionados como features.
